# FinTree Placements Plugin

A Moodle plugin for student placement and recruitment workflows, built by Shreyash Sakhare during his employment at FinTree Education.

**Attribution:** this is historical employer work for FinTree Education, not an independent commercial product.

## What the repository contains

- The Moodle plugin under [`local/finplacements`](local/finplacements).
- Candidate and administrator capabilities, application workflows, scoring, and background integration tasks.
- Implementation notes and testing checklists.

Start with the [plugin documentation](local/finplacements/README.md), [version requirements](local/finplacements/version.php), and [testing checklist](TEST_CHECKLIST.md).

This plugin requires a compatible Moodle installation and administrator configuration. WhatsApp and spreadsheet integrations require the institution’s own settings. No live student data or production credentials are needed to read the code.

The presence of code and checklists does not establish that this checkout has passed a fresh deployment test.
